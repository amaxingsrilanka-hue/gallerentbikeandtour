GALLE RENT BIKE & TOURS — SIMPLE PHOTO ADMIN PANEL

INSTALL
1. Download and extract this ZIP.
2. Upload/replace the files in the root of your GitHub repository (same place as index.html). Replace admin.html and keep the other site files.
3. Open https://amaxingsrilanka-hue.github.io/gallerentbikeandtour/admin.html
4. There is no separate front-end password gate in this troubleshooting panel. GitHub repository permissions are what authorize uploads.
5. Enter owner amaxingsrilanka-hue, repository gallerentbikeandtour, branch main.
6. Paste a GitHub fine-grained personal access token that is limited to this repository and has Contents -> Read and write. Click Test connection.
7. After a successful connection, use Upload Photos, Bikes & Tuk-tuks, or Homepage Photos.

IMPORTANT
- Never share your token in chat or commit it into website files.
- The token is kept in sessionStorage for this browser session; owner/repo/branch preferences are stored in localStorage.
- GitHub's Contents API requires Contents: write permission to upload files.
- If Test connection fails, read the exact HTTP error in the status box. A 401 usually means invalid/expired token; 403 usually means missing permission; 404 usually means wrong repo/branch or token lacks repository access.
- This panel saves uploaded photos to media/ and vehicle details to site-data.json. The public pages must read/render the fleet array to display new vehicles; this admin stores the fleet data, but an older public-page design may not automatically show a new fleet section.
