How this works

This panel publishes changes directly to your GitHub repository through GitHub's Contents API. Your token is kept only in this browser session. Public pages read site-data.json and update their images/text automatically.

Security: do not put a GitHub token into the website code or share it with anyone. Use a fine-grained token limited to this repository and Contents read/write.
