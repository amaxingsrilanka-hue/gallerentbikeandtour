How this simple panel works

Choose photos and edit your vehicles here. Then click Download updated site-data.json and upload that one file to your GitHub website repository to publish the changes. This panel does not ask for a password or GitHub token.

Photos are stored inside the JSON file as compressed data. Use images under about 1 MB each so the data file does not become too large.

First load the site-data.json from this ZIP, then edit photos or vehicles.

Finish and publish

  1. Click Download updated site-data.json.
  2. Open your GitHub repository and upload/replace site-data.json in the root folder.
  3. Wait a minute, then refresh your website.

Because GitHub Pages is static hosting, a no-token admin panel cannot directly change the live website. This workflow avoids GitHub tokens: upload only the downloaded JSON file manually after editing.
